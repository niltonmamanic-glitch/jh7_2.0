JH7 TELECOM 2.0

Sistema de Gestión de Servicios Técnicos

Aplicación web desarrollada para JH7 SRL TELECOM, que permite gestionar clientes, servicios, técnicos, solicitudes, órdenes de trabajo y seguimientos.

Incluye reportes de gestión y un asistente de inteligencia artificial para apoyar el diagnóstico de problemas técnicos de telecomunicaciones.

Tecnologías: Python, Flask, Flask-AppBuilder, MySQL, HTML y CSS.

Proyecto académico – Taller de Aplicaciones.
